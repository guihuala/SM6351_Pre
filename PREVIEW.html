Data source & processing notes

Where categories are absent, we show gaps instead of inventing zeros. Combined totals sum available categories and are marked as partial when the expected categories are not all present. A missing category may reflect reporting practice or no service; this dataset alone does not distinguish those cases.

Full-year availability means 12 reporting months exist somewhere in the dataset, not that every terminal and category has complete coverage. Year-to-date periods should be compared with matching months.

STEP 1 · js/lax-data.js

Read the CSV and parse the fields

CSV values are strings. Convert the count to a number and the report period to a UTC month. DataExtractDate is a version timestamp, not the chart’s time axis.

KEY CODE / JAVASCRIPT

const parseMonth = d3.utcParse('%Y-%m');
const source = await d3.csv(app.config.source);
// Inside the row loop:
const date = parseMonth(row.reportperiod.slice(0,7));
const value = row.passenger_count.trim() === ''
  ? NaN : Number(row.passenger_count);

Expected result: Each valid record has a Date and a numeric count. The loader also rejects invalid rows and resolves repeated reporting cells before grouping.

STEP 2 · js/lax-data.js

Group records by terminal, month and traffic

Filter years and arrivals/departures first. Use a numeric timestamp as the month key: distinct Date objects can represent the same month.

KEY CODE / JAVASCRIPT

const grouped = d3.group(
  rows,
  d => d.terminal,
  d => +d.date,
  d => d.traffic
);

Expected result: A nested Map: terminal → month timestamp → Domestic or International → records. A month’s arrival and departure rows belong to the same traffic group.

STEP 3 · js/lax-data.js

Align every panel to the same months

Loop over the common month sequence, even if a terminal has no record for a month. Sum available movements and keep missing values distinct from zero.

KEY CODE / JAVASCRIPT

const cell = grouped.get(terminal)?.get(+date);
const records = cell?.get(type) || [];
point[type] = {
  value: records.length ? d3.sum(records, d => d.value) : null,
  count: records.length,
  expected
};

Expected result: Each panel has the same date positions. A value is null when the category has no record; count and expected allow partial sums to be labelled. With both directions selected, expected is 2 per traffic category.

STEP 4 · js/lax-charts.js

Create shared axes, then repeat the panel

Define the time scale once. For a shared vertical scale, compute the maximum across all panels, not inside each panel independently.

KEY CODE / JAVASCRIPT

const x = d3.scaleUtc()
  .domain(d3.extent(view.months))
  .range([m.l, width - m.r]);
const globalMax = d3.max(view.panels,
  p => maxFor(p, view.series)) || 1;
// Inside the panel loop, initially use a shared scale:
const y = d3.scaleLinear()
  .domain([0, globalMax]).nice()
  .range([height - m.b, m.t]);
const card = grid.append('article').attr('class', 'chart-card');

Expected result: One panel per terminal, with matching time and count coordinates. The renderer adds one SVG and two axes to every card. maxFor reads the maximum selected series value in one panel.

STEP 5 · js/lax-charts.js

Draw the lines and preserve gaps

Repeat for each selected series. The defined predicate prevents a missing month from being connected as though data existed.

KEY CODE / JAVASCRIPT

const line = d3.line()
  .defined(p => p[type].value !== null)
  .x(p => x(p.date))
  .y(p => y(p[type].value));
svg.append('path')
  .datum(panel.values)
  .attr('d', line)
  .attr('fill', 'none')
  .attr('stroke', cfg.colors[type]);

Expected result: A line for each traffic category in every terminal. The full renderer also adds dots for isolated values, an international dash pattern, axes and labels.

STEP 1 · js/lax-charts.js

Switch the vertical scale

The radio group in main.js updates state.scale. Use one global maximum for comparing volume, or each panel’s maximum for comparing shape.

KEY CODE / JAVASCRIPT

const y = d3.scaleLinear()
  .domain([0, state.scale === 'shared'
    ? globalMax
    : maxFor(panel, view.series)])
  .nice()
  .range([height - m.b, m.t]);

Expected result: In independent mode, labels show each panel’s own upper limit. All axes still start at zero. Heights cannot be compared between independent panels.

STEP 2 · js/lax-data.js

Filter before you draw

A movement filter changes the rows being aggregated. A traffic filter chooses which aggregated series are displayed and counted in the ranking.

KEY CODE / JAVASCRIPT

const rows = data.rows.filter(d =>
  d.date.getUTCFullYear() >= state.start &&
  d.date.getUTCFullYear() <= state.end &&
  (state.direction === 'All' || d.direction === state.direction)
);
const series = state.traffic === 'Both'
  ? ['Domestic', 'International']
  : [state.traffic];

Expected result: The chart, reported-volume order and selected-month table use the current state. Do not merely hide a line while leaving summary totals unchanged.

STEP 3 · js/main.js

Connect the controls to state

The traffic radio group emits a change event. Read the selected value, update state and redraw. This focused example matches the handler in main.js; do not register it twice.

KEY CODE / JAVASCRIPT

// Focused example of the existing handler:
$('traffic').addEventListener('change', event => {
  state.traffic = event.target.value;
  clearPreset();
  syncControls();
  render();
});

Expected result: render() calls aggregate(), rebuilds the panels and summary, then restores the selected month if it still exists in the new range.

STEP 4 · optional · js/lax-charts.js

Link the same month across panels

Convert the pointer’s x-position back into a date, find the nearest month, and send its index to the shared callback. All panels use the same month array.

KEY CODE / JAVASCRIPT

const date = x.invert(d3.pointer(event, this)[0]);
const index = d3.bisector(d => +d).center(view.months, +date);
onMonth(index);

Expected result: The selectMonth callback in main.js updates the slider, month label, every panel’s cursor and the table. Keyboard users can use the month slider instead of hovering.
